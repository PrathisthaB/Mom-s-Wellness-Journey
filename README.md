# 🌸 Mom's Wellness Journey – A Mother's Day Tribute Blog

**Live Demo**: [mom-s-wellness-journey.vercel.app](https://mom-s-wellness-journey.vercel.app)

Crafted with love , this multi-page React.js blog is a heartfelt tribute to mothers everywhere. Designed as a cozy digital nook, it empowers moms to rediscover "me-time" through inspiring content, wellness guides, healthy recipes, and self-care tips.

---

## 🌟 Highlights

- 💖 Heartwarming stories celebrating motherhood
- 🥗 Easy and healthy recipe guides
- 🧘 Self-care and wellness tips
- 📚 Multi-page responsive layout
- 🎨 Figma-based design implementation

---

## 🛠️ Tech Stack

- **Frontend**: React.js (with React Router)
- **Styling**: CSS Modules / TailwindCSS (based on your implementation)
